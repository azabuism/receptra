```python

└─ REST API エンドポイント 15個
```

#### 3️⃣ IVR（音声対話）設計
- **電話対応フロー**: 着信 → ウェルカムメッセージ → 予約/照会選択 → 詳細情報入力 → 確認 → DB保存
- **リマインドフロー**: 予約前日自動発信 → 顧客情報確認 → カスタム質問 → 回答記録 → 完了通知
