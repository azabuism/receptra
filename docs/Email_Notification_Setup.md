# 📧 メール通知機能 セットアップガイド

Google Apps Script を使用した自動メール送信機能の設定方法です。

---

## ✨ メール通知でできること

### ユーザーに送信されるメール
- ✅ **予約確認メール** - 予約入力直後に送信
- ✅ 予約内容の詳細表示
- ✅ 予約ID (確認に便利)
- ✅ 店舗への連絡方法

### オーナーに送信されるメール
- ✅ **新規予約通知** - 予約が入ったらすぐに送信
- ✅ 顧客情報（名前、メール、連絡先）
- ✅ 予約日時と人数
- ✅ 対応アクション（確定/キャンセル）

---

## 🚀 セットアップ手順

### ステップ1️⃣ 新しい Google Apps Script コードを適用

1. Google Sheets で **拡張機能 > Apps Script** を開く
2. 現在のコードをすべて削除
3. 以下のファイルの内容を**すべてコピー**してペースト：
   - `Google_Apps_Script_Complete.gs`
4. **💾 保存** をクリック

### ステップ2️⃣ テスト実行

1. 左側メニューの **「実行」** をクリック
2. 関数選択で **「testEmailDelivery」** を選択
3. **実行** ボタンをクリック
4. 初回実行時は、Google にアクセス許可を求められます：
   - **「このプロジェクトのアクセス権限を確認」** をクリック
   - 自分のアカウントを選択
   - **「詳細」→「〇〇（未確認）に移動」** をクリック
   - **「許可」** をクリック
5. 実行ログに「テスト完了！メールをご確認ください。」と表示されたら成功！
6. メール受信箱にテストメールが届いているか確認

### ステップ3️⃣ デプロイ（前回と同じ手順）

すでに Google Apps Script をデプロイしている場合：

1. 左側メニューの **「デプロイ」** をクリック
2. 新しいURLを作成する場合：
   - **「新しいデプロイ」** をクリック
   - タイプ：**「ウェブアプリ」**
   - 実行者：**「自分」**
   - アクセス権限：**「全員」**
   - デプロイ → URL をコピー
3. この URL を RECEPTRA アプリに設定

## 📨 メール送信フロー

```
ユーザーが予約入力
    ↓
HTML から Google Apps Script に POST
    ↓
【GAS 処理】
├─ スプレッドシートに記録
├─ ユーザーにメール送信
└─ オーナーにメール送信
    ↓
ユーザー：「ご予約ありがとうございます」メール受信
オーナー：「新しい予約が入りました」メール受信
```

## 🎨 メールのカスタマイズ

### 店舗名の表示
メール内に自動的に店舗名が表示されます（`data.shopName`）

### 送信者名の変更
Google Apps Script 内の以下の行を編集：

```javascript
const EMAIL_SENDER_NAME = 'RECEPTRA 予約管理'; // ← この部分を変更
```

例：
```javascript
const EMAIL_SENDER_NAME = '渚の寿司'; // 店舗名を表示
```

### メール文面のカスタマイズ

`sendUserConfirmationEmail()` 関数内の HTML を編集します。

**編集できる部分：**
- メール本文のテキスト
- 色（`background: #FF7A00` など）
- フォント
- ロゴ画像（URL指定可能）

## 🔧 トラブルシューティング

### Q: メールが送信されない

**A:** 以下を確認してください：

1. **デプロイが完了しているか**
   - 新しいコードに変更した場合は、新しくデプロイしてください
   - 新しい URL が RECEPTRA に設定されているか確認

2. **テスト実行は成功しているか**
   ```javascript
   testEmailDelivery() // スクリプトエディタから実行
   ```
   - ログに「テスト完了」と表示されるか確認

3. **Gmail が正常に機能しているか**
   - Gmail を直接開いてみる
   - スパムフォルダを確認

### Q: メールがスパムフォルダに入る

**A:** 正常な動作です。以下の対策をしてください：

1. メールを「迷惑メールではない」としてマーク
2. メール送信者を連絡先に追加

3. **メール認証の強化（オプション）**
   
   Apps Script のメール送信部分にこれを追加：
   ```javascript
   {
     htmlBody: htmlBody,
     name: EMAIL_SENDER_NAME,
     replyTo: 'your-email@gmail.com', // 実際のメールアドレスに変更
     from: 'your-email@gmail.com'
   }
   ```

### Q: 「このプロジェクトは確認されていません」と出た

**A:** Google による確認が必要なメッセージです。以下の手順で対応：

1. メッセージ内の **「詳細」** をクリック
2. ページ下部の **「〇〇（セキュリティなし）に移動」** をクリック
3. **「許可」** をクリック

これは自分のスクリプトなので安全です。

## 📊 ログ確認方法

Google Apps Script エディタで、メール送信のログを確認できます：

1. **「実行ログ」** タブをクリック
2. 最新の実行結果を確認
3. エラーがあれば表示されます

例：
```
[23-12-15 14:32:10:123 JST] ユーザーメール送信成功: user@example.com
[23-12-15 14:32:12:456 JST] オーナーメール送信成功: owner@gmail.com
```

## 🔐 セキュリティに関する注意

### 現在の設定
- メール送信は自動化されています
- スプレッドシート所有者（オーナー）のメールアドレスを自動取得
- ユーザーのメールアドレスはフォームから受け取ります

### 推奨される改善（オプション）

1. **メール送信数の制限**
   ```javascript
   // 1日1000件まで等の制限を設定可能
   MailApp.getRemainingDailyQuota() // 残数を確認
   ```

2. **ログの定期削除**
   - Apps Script のログは自動削除されます
   - 手動削除不要

3. **テスト環境と本番環境の分離**
   - テスト用に別の GAS プロジェクトを作成
   - 本番用の URL に切り替える前にテスト実施
