# ランキング・統計ページ実装完了

## 📊 実装内容

RECEPTRA アプリケーションの **ランキング・統計ページ** が完成しました。オーナーダッシュボードから「📊 統計」ボタンをクリックすることで、店舗のビジネス分析ダッシュボードにアクセスできます。

---

## ✨ 実装された機能

### 1. **全体統計表示**
- 📊 総予約数：全店舗の累計予約件数を表示
- 💬 総レビュー数：全店舗の累計レビュー件数を表示

### 2. **人気店ランキング（評価順）**
- ⭐ 各店舗の平均評価をランキング表示（上位10件）
- レビュー件数も併せて表示
- 高い評価順に自動ソート

### 3. **予約数ランキング**
- 📈 各店舗の予約数をランキング表示（上位10件）
- 予約の多い順に自動ソート
- ビジュアルなカウント表示

### 4. **ジャンル別統計**
- 🍽️ ジャンルごとの予約数集計
- ジャンル別の人気度を一目で把握可能

### 5. **全店舗平均評価**
- 💬 全店舗を合わせた平均評価を表示
- 大きく見やすいフォント

---

## 🔧 実装された JavaScript 関数

### `showRankingsPage()`
- ランキング・統計ページを表示
- ページスタックを更新
- 統計データを自動読み込み

### `loadRankingsData()`
- localStorage から予約とレビューデータを読み込み
- 統計値を計算して各セクションに表示
- 全ての表示データを一括更新

### `renderRatingRankings(reviews)`
- レビューデータから店舗ごとの平均評価を計算
- 評価が高い順にソート（上位10件）
- 各店舗の評価とレビュー件数を表示

### `renderReservationRankings(reservations)`
- 予約データから店舗ごとの予約数を集計
- 予約数が多い順にソート（上位10件）
- 視覚的なカウント表示

### `renderGenreStats(reservations)`
- ジャンルごとの予約数を集計
- ジャンル別の予約数でソート
- ジャンルの人気度を視覚化

### `renderAverageRating(reviews)`
- 全店舗の平均評価を計算
- 大きく表示可能な形式で出力

## 🎯 使い方

### ページへのアクセス方法
1. RECEPTRA アプリにオーナーとしてログイン
2. 店舗管理セクションの「📊 統計」ボタンをクリック
3. ランキング・統計ページが表示されます

### 表示される情報
- **上部**：全体統計（総予約数、総レビュー数）
- **中上部**：人気店ランキング（評価順）
- **中央部**：予約数ランキング
- **下部**：ジャンル別予約数
- **最下部**：全店舗の平均評価

### 戻り方
- ページ左上の「← 戻る」ボタンで店舗管理ページに戻ります

## 💾 データ連携

### 使用するデータソース
- **予約データ**：localStorage の `receptra_reservations` キーから取得
- **レビューデータ**：localStorage の `receptra_reviews` キーから取得
- **店舗データ**：`ownerState.shops` から取得

### データ更新タイミング
- ランキング・統計ページを開くたびに自動更新
- リアルタイムでデータが反映されます

## 🔄 ナビゲーション統合

### ページスタック更新
- `showRankingsPage()` 実行時に 'rankings' をスタックに追加
- `goBack()` 関数が 'rankings' ページを認識
- 戻る際に適切なページに遷移

### hideAllPages() 更新
- rankingsPage を隠すロジックを追加
- 他のページ表示時に統計ページが隠れる
